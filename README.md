# Speex – A Basic Python Voice Assistant

**Speex** is a simple Python-based voice interaction tool that includes text-to-speech (TTS) and speech-to-text (STT) capabilities. It demonstrates how voice-based automation can be used in small desktop or utility applications.

## 🎯 Purpose

To experiment with basic voice-based interactions using Python and explore how simple audio input/output could enhance user engagement in real-time systems.

## 🛠 Features

- Play pre-recorded audio on launch
- Convert written text to speech
- (If implemented) Convert user voice to text commands
- Lightweight and beginner-friendly

## 🔧 Technologies Used

- Python
- `gTTS` / `pyttsx3` (for TTS)
- `speech_recognition` (for STT, if applicable)
- Basic audio handling (`playsound`, `pydub`)

## 📁 Folder Content

- `SPEEX.py` – Main runner script
- `Speech.mp3`, `intro.mp3` – Audio files
- `TTS1.png` – Reference image or interface
- `__pycache__` – Cached compiled Python files

## 📌 Notes

This project is a basic prototype and not intended for production use. It was created for learning purposes and to explore how speech tech can be used in lightweight personal or business tools.
